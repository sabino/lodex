# Lodex development

Lodex is a MIPS/OpenWrt headless Codex fork. Preserve Remote, authentication,
resumable threads, local execution and MCP interoperability. Keep application
integrations and application-specific personalities outside the runtime.

Use measured comparisons. Never equate executable size, virtual reservations,
RSS, or process swap. Benchmark isolated candidates first. Preserve a working
rollback and validate Remote after a device cutover. Keep remote access intact.

Keep personality and memory storage external to the repository. Do not collect
prompts, transcripts, environment variables or credentials for performance
profiling. Cloud worker payloads require an explicit data boundary; local file
storage does not imply local model inference.

For MIPS use the matching soft-float OpenWrt SDK. Keep upstream licenses and
protocol versions. Dependency replacements require conformance/regression tests
and a measured improvement. Do not claim compatibility from compilation alone.

Read docs/lodex/plan.md for milestones and docs/lodex/contract.md for required
capabilities. The current stock installation is rollback material.
